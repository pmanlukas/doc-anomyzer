Bitte über das Programmsymbol öffnen

Diese Seite ist geschützt, damit niemand außer Ihnen auf Ihre Dokumente zugreifen kann.

So geht es weiter: Doppelklick auf das Symbol „Dokumenten-Anonymisierer“ auf dem Desktop oder im Startmenü. Das Programm öffnet sich dann von selbst – dieses Fenster können Sie schließen.
